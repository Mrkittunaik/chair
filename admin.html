Admin — quick guide

The store's admin panel lives inside the main site (index.html) so it can share the same product catalogue, categories and homepage content without a separate backend. This page is a standalone reference: what each admin section does, and a shortcut into the panel itself.

Open admin panel → View storefront
Dashboard

Overview & recent orders

Product, category and order counts, total revenue, pending-order count, and the 5 most recent orders with quick links.

Go to Dashboard →
New

Orders

Every order placed at checkout: customer details, items, totals, and a status you can move through pending → confirmed → shipped → delivered (or cancelled).

Go to Orders →
Catalogue

Products

Add, edit or delete products — name, category, price, material, color, rating, description, image upload, and a featured flag.

Go to Products →
Catalogue

Categories

Create or relabel the room/category groups products belong to (Office, Gaming, Sofas, etc). A category in use by products can't be removed.

Go to Categories →
Content

Homepage

Edit the hero banner, two featured product rows, about section, promo banner, and the 6-card collections grid — all with image upload and show/hide toggles.

Go to Homepage →
New

Settings

Site name, contact phone/email/address (shown on the Contact page and footer), free-delivery threshold, and delivery cost — plus data export/import for backups.

Go to Settings →
How data is stored: everything the admin panel manages (products, categories, homepage content, orders and settings) is saved in this browser's localStorage — there is no external server or database. That means data is per-browser and per-device. Use Settings → Backup & restore to export a JSON snapshot and re-import it on another device or after clearing browser data.

Once this site is hosted, your admin link will be that URL followed by #/admin. Keep it private — anyone with the link and PIN can manage the store.
